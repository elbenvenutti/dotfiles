# Self Improvement Protocol

## Purpose
Continuously improve guardrails without unapproved rule churn.

## When to load
- After discovering a repeated mistake pattern.

## Non-negotiable rules
- Ask the user before adding or changing rules.
- Add rule updates only after explicit approval.
- New rules must be concrete, specific, and actionable.

## Workflow
1. Describe the mistake and impact.
2. Ask for permission to add a rule.
3. If approved, propose precise wording and location.
4. Apply and report the update.
